Глава 2. Деплой.
Hardhat - целый фреймворк, который позволяет нам на своем компьютере:
   Компилировать контракты.
   Запускать локальный блокчейн для тестов (больше не нужен Remix VM).
   Писать автоматизированные тесты, чтобы быть уверенными, что наш код работает как часы.
   Писать скрипты для деплоя, чтобы разворачивать контракты в реальные сети одной командой.
Вся эта экосистема работает на Node.js — это среда, которая позволяет запускать JavaScript (и его старшего брата TypeScript) не в браузере, а прямо на компьютере. Мы будем использовать TypeScript, потому что он добавляет строгую типизацию и помогает избежать 90% глупых ошибок еще до запуска кода.

    События (Events) - Новая концепция!
        Объявите событие в контракте: event Operation(address indexed user, string operationType, int256 value, int256 result);
        В конце каждой функции-операции (add, subtract и т.д.) добавляйте вызов emit для этого события. Например, в функции add: emit Operation(msg.sender, "ADD", value, currentResult);.
        События - это "чекпоинты" в блокчейне. Они ничего не стоят в плане вычислений, но позволяют внешним приложениям (и нам в тестах) легко отслеживать, что произошло внутри контракта, не читая все его переменные.
    Модификаторы (Modifiers) - Новая концепция!
        Создайте private переменную address public owner;. В constructor установите ее в msg.sender.
        Создайте modifier под названием onlyOwner. Внутри него должна быть проверка require(msg.sender == owner, "Only owner can call this function"); и _;.
        Создайте функцию reset() которая сбрасывает currentResult на 0. Защитите ее модификатором onlyOwner.
